# Project — Salesforce Experience Cloud Portfolio Site with Agentforce Agent

Date: May 2026 | Geneva, Switzerland
Link: https://vinaegg-dev-ed.develop.my.site.com/portfolio/s/ (this site)

Vina developed and built this public-facing Experience Cloud site (Home, About Me, Certifications, Projects, Contact) to demonstrate end-to-end Salesforce configuration skills.

She configured this Agentforce agent — the one you're talking to right now — grounded on a Data Cloud Data Library, and integrated it with Omni-Channel routing, Omni-Channel Flow, and Enhanced Messaging to model a real support workflow.

She also built lead-capture automation using Screen Flows, Email Templates, and Org-Wide Email Addresses, and created dynamic content (the certifications carousel) via Salesforce CMS Workspaces.
